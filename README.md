# social

Grafiche e testi dei post social dei prodotti Nexa: Sanly, Fatturo, ScrivaniaInCloud, Synecho.

Il repository è pubblico perché Metricool legge le immagini dai loro indirizzi pubblici
(`https://raw.githubusercontent.com/affittoincloud/social/main/...`). Qui va solo materiale
destinato a essere pubblicato: niente dati di clienti, chiavi o documenti interni.

## Struttura

```
<prodotto>/<anno-mese>/<data>_<titolo-breve>/
    slide-1.png … slide-N.png   caroselli (1080 × 1350)
    post.png                    post singoli (1080 × 1350)
    copertina.png               copertine dei reel (1080 × 1920)
    storia.png                  storie (1080 × 1920)
    caption.md                  caption, hashtag, data prevista e stato
```

`<prodotto>/riserva/` raccoglie i contenuti pronti ma non ancora in calendario (reel senza video, storie con sticker, post tolti).

Cartelle dei prodotti: `sanly/`, `fatturo/`, `scrivaniaincloud/`, `synecho/`.
